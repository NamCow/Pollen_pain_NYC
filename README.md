# Pollen & Pain: Forecasting Neighborhood-Level Asthma ED Surges in NYC

## Team
- Saketh Boddu
- Andre Nguyen
- Nam Lai

## Project Overview
This project forecasts monthly asthma emergency department visit surges across NYC at the NTA level using pollen, weather, asthma ED records, tree canopy, 311 complaints, CHS data, and Reddit activity.

## Tech Stack
- Python
- PostgreSQL
- MongoDB
- XGBoost
- Logistic Regression
- Streamlit

## Repository Structure
- `data/`: raw, processed, and external datasets
- `src/etl/`: ingestion and dataset alignment
- `src/features/`: feature engineering
- `src/models/`: training, evaluation, prediction
- `src/dashboard/`: Streamlit app
- `database/`: schemas and DB notes
- `docs/`: proposal and project documentation
