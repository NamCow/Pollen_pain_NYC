Add data transformation pipeline and XGBoost model training

Transform scripts process raw data into modeling features:
- weather: daily→monthly aggregation per NTA
- pollen: composite index + 2-week/4-week lag features
- air_quality: merge EPA 2022-2024 + AirNow 2025
- tree_canopy: spatial join of 683k trees to NTA2020
- chs_baseline: UHF42 asthma prevalence mapped to NTAs
- complaints_311: monthly complaint counts by borough
- build_modeling_table: joins all features + target (8,865 rows, 26 cols)

XGBoost model uses walk-forward time-series CV with logistic regression baseline.
